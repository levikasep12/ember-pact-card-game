Ember Pact is an original duel card game: you and Rook, the Ember Warden, play one card a round from a hand of five. Four elements — Ember, Tide, Gale, Stone — beat each other in a cycle worth +3 power, and Mend, Ward, Siphon and Wild cards turn a losing hand into a comeback. First to 0 life loses the pact.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is plain static files under `game/`.
